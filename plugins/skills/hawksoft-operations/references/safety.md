# HawkSoft Safety Reference

Before writing, saving, submitting, binding, deleting, or canceling anything in HawkSoft:

1. Verify the correct client.
2. Verify the relevant policy or account context when applicable.
3. Draft the proposed note or action.
4. Ask the user for approval.
5. Continue only after approval.

Never include full Social Security numbers, payment-card numbers, passwords, security answers, or unrelated customer information in examples or logs.
