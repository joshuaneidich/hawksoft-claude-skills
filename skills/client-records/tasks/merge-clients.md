# Merge clients

## Purpose

Combine two duplicate client records into one.

## Screen path

Use this exact action path:

Action → Internal → Merge Clients

## Required information

Before beginning, obtain:

- Both client records to merge
- Which record is the one to keep

If the user has not provided enough information, ask for the missing details before starting.
