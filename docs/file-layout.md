# File Layout

The repository is organized into four layers:

1. Root files for project metadata and high-level documentation.
2. `workflows/` for vendor-neutral HawkSoft procedures.
3. `skills/` for canonical agent-facing skill instructions and shared references.
4. `plugins/claude/` for the Claude plugin adapter that packages the skill for Claude.

Use `.gitkeep` files only to preserve intentionally empty folders in Git.
